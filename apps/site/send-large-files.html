Why there is no size limitSize limit क्यों नहीं है

Cloud transfer services have limits because they must store your file first and pay for that storage. Narad never stores the file: it opens an encrypted peer‑to‑peer connection (WebRTC) between the two devices and streams the bytes in back‑pressured chunks straight to disk. Nothing sits in RAM, nothing sits on a server, so there is nothing to cap.Cloud transfer services में limit इसलिए है क्योंकि उन्हें पहले आपकी फाइल store करनी पड़ती है और उसका खर्च उठाना पड़ता है। Narad फाइल कभी store नहीं करता: दो डिवाइसों के बीच encrypted peer‑to‑peer कनेक्शन (WebRTC) खोलकर bytes को chunks में सीधे disk पर stream करता है। न RAM में कुछ, न सर्वर पर, तो cap किस बात का।

Resumable transfersResumable transfer

If the connection drops at 80%, both devices keep their state: the sender keeps the file handle, the receiver keeps the open file and byte count. When they reconnect, the transfer continues from that byte. The resume window is 10 minutes; after a page reload the receiver asks for a clean restart instead.कनेक्शन 80% पर टूटे तो दोनों डिवाइस अपनी state रखते हैं: भेजने वाला file handle, पाने वाला खुली फाइल और byte count। दोबारा जुड़ते ही transfer उसी byte से आगे चलता है। Resume window 10 मिनट है; page reload के बाद पाने वाला साफ़ restart माँगता है।

FAQ

What is the maximum file size I can send?

There is no maximum. Narad streams the file from the sender’s disk to the receiver’s disk in chunks, so a 50 GB video uses the same memory as a photo. The only limit is the receiver’s free disk space.

How fast is it?

On the same Wi‑Fi, typically 20–80 MB/s (your router is the limit). Over the internet it is bounded by the slower side’s upload speed, since the file goes directly between the devices without a server hop.

What happens if the connection drops halfway?

Both sides freeze the transfer. When the devices see each other again (within 10 minutes) Narad resumes from the last byte that arrived. You never restart from zero.

Can I send a whole folder?

Yes. Drag a folder in (or use the folder button). The structure is recreated on the other side. On desktop Chrome and Edge files are written directly to the folder you choose; other browsers download as usual.

Do I need to compress or zip the files first?

No. Send them as they are. Compression would only add a step; the bottleneck is the network, not the file format.

Type the 6‑digit code the sender gave you. The app opens and the transfer starts, device to device.भेजने वाले का 6 अंकों का कोड डालें। App खुलेगा और transfer डिवाइस‑से‑डिवाइस शुरू होगा।
