01 — Ways inरास्ते

Three ways to reach a device. One kind of connection.डिवाइस तक तीन रास्ते। कनेक्शन एक ही तरह का।

However two devices find each other, the bytes travel on a direct, encrypted channel between them. Our server only makes the introduction.दो डिवाइस चाहे जैसे मिलें, डेटा उनके बीच सीधे, encrypted चैनल पर जाता है। हमारा सर्वर सिर्फ़ परिचय कराता है।

01

Share with a codeकोड से भेजो

For anyone, anywhere. A 6‑digit code, said out loud or sent as a link. No account on either side.किसी के लिए भी, कहीं भी। 6 अंकों का कोड, बोल कर या लिंक से। दोनों तरफ़ बिना अकाउंट।

 02

03 — Securityसुरक्षा

What our server sees. And what it never can.हमारा सर्वर क्या देखता है। और क्या कभी नहीं।

Most “private” sharing tools are private by policy. Narad is private by construction: the server only ever handles an introduction.ज़्यादातर “private” tools policy से private हैं। Narad बनावट से private है: सर्वर सिर्फ़ परिचय कराता है।

The server seesसर्वर देखता है
  • Your IP addressआपका IP address — needed to introduce two devices.दो डिवाइस मिलाने के लिए ज़रूरी।
  • A random session idएक random session id — new on every reload.हर reload पर नया।
  • Your device nameआपके डिवाइस का नाम — so the other side knows who is calling.ताकि दूसरी तरफ़ पता हो कौन है।
  • Which room you are inआप किस room में हैं — as a hash, while you are in it.hash के रूप में, जब तक उसमें हो।
The server never seesसर्वर कभी नहीं देखता
  • File contentsफाइल का content — bytes go device to device, encrypted with AES‑256‑GCM.डेटा डिवाइस‑से‑डिवाइस, AES‑256‑GCM से encrypted।
  • File names or sizesफाइल के नाम या size — metadata rides inside the encrypted channel.metadata भी encrypted चैनल के अंदर।
  • Your messages or clipboardआपके मैसेज या क्लिपबोर्ड — same channel, same keys.वही चैनल, वही keys।
  • Your contacts or codesआपके contacts या कोड — secrets live on your devices and in links, never on our side.secrets आपके डिवाइस और लिंक में, हमारे पास कभी नहीं।

06 — FAQ

Questions people actually ask.जो सवाल लोग सच में पूछते हैं।

Is Narad really free to send files online?क्या Narad से फाइल भेजना सच में मुफ़्त है?

Yes. Personal use is free with no size limit, no account and no ads. Teams pay ₹149 per user per month for shared spaces, priority relays and an admin console.हाँ। Personal use मुफ़्त है: न size limit, न अकाउंट, न ads। टीमें shared spaces, priority relay और admin console के लिए ₹149/user/महीना देती हैं।

How do I share a file with someone who doesn’t have Narad?जिसके पास Narad नहीं है उसे फाइल कैसे भेजूँ?

Open Narad, add the file or text, tap “Share with code”. Tell them the 6‑digit code; they type it at narad.sh/receive in any browser. Nothing to install on either side.Narad खोलें, फाइल या टेक्स्ट जोड़ें, “कोड से भेजें” दबाएँ। उन्हें 6 अंकों का कोड बताएँ; वे narad.sh/receive पर किसी भी ब्राउज़र में डालें। दोनों तरफ़ कुछ install नहीं।

Is there a file size limit?क्या file size की limit है?

No. Files stream directly from one device to the other and are written straight to disk, so a 20 GB video works as well as a 2 KB note. If the Wi‑Fi drops, the transfer resumes from the last byte.नहीं। फाइल एक डिवाइस से दूसरे पर सीधे stream होकर disk पर लिखी जाती है, इसलिए 20 GB वीडियो भी 2 KB note जितनी आसानी से जाता है। Wi‑Fi टूटे तो उसी byte से आगे चलता है।

Do both devices need to be online?क्या दोनों डिवाइस ऑनलाइन होने चाहिए?

Yes. Narad is device‑to‑device; there is no cloud copy. That is exactly why nothing is stored anywhere. If a contact is offline you can “nudge” them with a push notification.हाँ। Narad डिवाइस‑से‑डिवाइस है; कोई cloud copy नहीं। इसीलिए कुछ भी कहीं store नहीं होता। Contact offline हो तो push notification से “nudge” कर सकते हैं।

What does the Narad server see?Narad का सर्वर क्या देखता है?

Your IP, a random session id, your device name and a hash of the room you are in. Never file names, sizes, text or content: everything travels inside an AES‑256‑GCM channel between the two devices.आपका IP, एक random session id, डिवाइस का नाम और room का hash। फाइल के नाम, size, टेक्स्ट या content कभी नहीं: सब कुछ दो डिवाइस के बीच AES‑256‑GCM चैनल में जाता है।

Does it work on iPhone and Android?क्या iPhone और Android पर चलता है?

Yes, in Safari and Chrome. No app store install: open app.narad.sh and add it to your home screen if you like. iPhone, Android, Windows, Mac and Linux all talk to each other.हाँ, Safari और Chrome में। App store से कुछ install नहीं: app.narad.sh खोलें और चाहें तो home screen पर जोड़ें। iPhone, Android, Windows, Mac और Linux सब आपस में बात करते हैं।

Open it on two devices. That’s the whole setup.दो डिवाइस पर खोलो। बस यही setup है।

No account, no install, no size limit. Narad is ready the second the page loads.न अकाउंट, न install, न size limit। पेज खुलते ही Narad तैयार।
